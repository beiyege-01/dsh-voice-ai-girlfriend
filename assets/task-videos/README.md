# task-videos（说话动画，自备）

这里放**模型回复时播放的说话动画视频**。视频文件**不随仓库分发**，请自行准备：

## 方式一：手动放入

把视频文件放进本目录即可，支持的格式：`.mp4` / `.webm` / `.ogg` / `.mov` / `.m4v`。

- 女友窗每 30 秒自动轮询一次目录，放入后无需刷新页面即可被识别
- 每次回复开始会**按顺序轮播**本目录的视频
- 建议文件名按顺序编号（`01.mp4`、`02.mp4`…），内容为数字人"开口说话"姿态的短循环动画

## 方式二：第三方 API 回传（实时数字人生成）

如果你的数字人由第三方服务实时生成视频，可以让它把生成的视频**回传到本目录**：

```python
# 示例：任意脚本把一段说话视频写入本目录
import shutil, requests

resp = requests.get("https://你的数字人API/generate", params={"text": "你好"}, stream=True)
with open("assets/task-videos/live-01.mp4", "wb") as f:
    shutil.copyfileobj(resp.raw, f)
```

- 文件名只要在支持格式内即可，写入后 30 秒内被女友窗自动拾取
- 想实时切换：不断写入新文件（如 `live-01.mp4` → `live-02.mp4`…），轮播会自动轮到它

## 不装会怎样？

**完全正常。** 目录为空时，回复期间女友窗保持播放 `bg-images/` 的空闲动画；放入视频后自动切换为说话动画。
